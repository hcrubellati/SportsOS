Dedicated Identity Boundary (Zero Personal Credentials)

Never use your personal Gmail or personal Apple/Google accounts to create project assets. Register a clean domain (e.g., apexperformance.io) and set up a Google Workspace or forwarder for admin@apexperformance.io.

  • Create the Firebase Project under admin@apexperformance.io.
  • Open Stripe and set up the business entity under the company EIN/LLC and the same admin email.
  • When transferring ownership later, you simply hand over primary ownership of the Google Workspace container or change the root email in 1 click.
2

Low-Maintenance Payments: Stripe Firebase Extension

Avoid writing custom Node.js webhook listeners that break over time. Install the official open-source Firebase extension: "Run Payments with Stripe" (firestore-stripe-payments).

// How the extension automates subscription sync:

1. User registers via Firebase Auth (UID created).

2. Client writes a checkout session document to: /users/{uid}/checkout_sessions/

3. Extension triggers Stripe Hosted Checkout and returns payment redirect URL.

4. Upon successful payment, extension automatically writes subscription status to /users/{uid}/subscriptions/.

3

Asset Handover Checklist (When You Sell / Transfer)

Firebase & Database Transfer

Go to Firebase Console > Project Settings > Users and Permissions. Add the buyer's email with the Owner role. Once accepted, demote and remove your user.

Stripe Account Transfer

Go to Stripe Dashboard > Settings > Team. Invite the buyer as Administrator. Navigate to Account Details and transfer the primary account representative.
